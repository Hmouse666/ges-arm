# GT911 触摸与 LVGL 排查

## GT911 初始化

本项目通过 EMIO GPIO 位模拟 I2C。需依次确认：

1. SCL/SDA 空闲时能被释放为高；
2. 上拉有效；
3. 地址扫描得到 ACK；
4. 复位和 INT 时序符合屏幕模块；
5. 配置区可写；
6. 配置版本、X 最大值、Y 最大值可读；
7. 触摸状态寄存器能刷新。

常见 7 位地址为 `0x14` 或 `0x5D`，对应 8 位写法可能是 `0x28` 或 `0xBA`。地址 ACK 成功不代表控制器已经使用正确配置。

## 坐标读取

GT911 常用寄存器：

- `0x8040`：命令/模式；
- `0x8047`：配置版本；
- `0x8140`：产品 ID；
- `0x8144`：固件版本；
- `0x814E`：状态；
- `0x8150`：第一个触摸点数据。

读取点坐标前检查 `0x814E` 的 buffer status；读取后必须写回清零，否则控制器可能不再产生下一次有效更新。

如果 `Xmax=800`、`Ymax=480` 能读到，但点寄存器始终为 0，应继续检查：

- INT 状态；
- 点数据读取长度；
- 状态清零时机；
- 配置下载后的复位；
- 排线方向和触摸 IC 的实际安装方向。

## 坐标映射

原始触摸坐标到 LCD/LVGL 坐标需要综合：

- 横竖屏方向；
- X/Y 交换；
- X 或 Y 镜像；
- LCD 可见区域偏移；
- LVGL 显示分辨率。

先显示一个已知位置的原点或角点，再测试四个角。不要只看中心点，否则镜像和交换错误可能互相抵消。

## LVGL 输入事件

- `LV_EVENT_PRESSED`：按下时触发；
- `LV_EVENT_RELEASED`：释放时触发；
- `LV_EVENT_CLICKED`：完整点击后触发；
- `LV_EVENT_VALUE_CHANGED`：值变化时触发。

任务锁定、长按、按下即计数等交互应使用按下/释放状态机，而不是只依赖 `CLICKED`。

触摸采样建议与 LVGL `lv_tick_inc`、`lv_timer_handler` 分开，避免一次读取阻塞界面刷新。

## 图片与透明背景

图片数组必须与 `lv_img_dsc_t` 头信息一致：

- 宽、高；
- color format；
- data size；
- stride；
- alpha 类型。

若数组来自外部转换工具，应比对工具导出的格式和手写头信息。RGB565 图片不能直接声称是 32 位 TRUE_COLOR_ALPHA；需要透明时，应生成带 alpha 的格式并确认 LVGL 配置启用了对应解码。

## 启动白闪

启动白闪通常来自背光先亮而帧缓存仍为空白。优先级：

1. PL 默认下拉背光；
2. PS 完成显示和 LVGL 首帧后再释放背光；
3. 减少从点屏到首帧之间的延时；
4. 不要把单纯增加延时当作根治方案。
