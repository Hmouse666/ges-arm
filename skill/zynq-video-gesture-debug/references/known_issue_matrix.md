# 症状到检查项

| 症状 | 首先确认 | 常见根因 | 最小验证 |
|---|---|---|---|
| 摄像头检测成功但 HDMI 全黑 | PL 是否配置、VTC/VDMA 是否运行 | VDMA 未启动、帧地址错误、背光/显示时钟未就绪 | ILA 看 AXIS handshake，串口打印 VDMA 状态 |
| HDMI 雪花 | 像素时钟与 AXIS 数据 | 时钟域不匹配、像素格式错误、TMDS 时序错误 | 固定彩条测试；逐级看 `tvalid/tdata` |
| LCD 花屏 | 第二路 VDMA、RGB 接口 | stride、颜色格式、VTC、引脚或显存混用 | 纯色/彩条；核对一行字节数 |
| LCD 全白 | 背光与帧缓存 | 背光提前拉高、首帧未生成、RGB 数据恒高 | 保持背光关闭，确认首帧完成后点亮 |
| 开机先红屏后动画 | 启动显示路径 | UI 首帧清屏色、背光时序、DDR 内容 | 先禁用背光，再看首帧缓冲 |
| GT911 有 ACK 但无坐标 | 配置版本、Xmax/Ymax、0x814E | 配置未下载、状态未清零、INT/复位错误 | 手动读点寄存器并打印状态字节 |
| 触摸坐标偏移 | 原始坐标与 LCD 方向 | X/Y 交换、镜像、旋转、偏移 | 依次点击四角记录 raw/display 坐标 |
| 按下按钮无动作 | LVGL 事件类型 | 只监听 `CLICKED`、按钮被遮挡、输入设备未注册 | 在 `PRESSED` 回调打印事件 |
| 串口无打印 | UART 编号与引脚 | 复用错误、COM 口错误、发送函数未调用 | 固定字符串周期发送 |
| 串口有乱码 | 波特率和时钟 | UART 时钟、双方参数不一致、编码混用 | 发送 ASCII `ABC123` |
| 串口数据全 0 | PL 输出与 GPIO | 调试信号未连接、GPIO 宽度/通道错误、`#define` 未更新 | ILA 同时看 PL 调试端口 |
| 手势远距离误判握拳 | 阈值尺度 | 固定像素阈值、面积变化 | 记录近/中/远框宽和 `zero_cnt` |
| ILA 不打开仿真页 | 探针与时钟 | ILA 核未进入比特流、debug hub 时钟错误、探针未触发 | 检查实现后 ILA 资源和 hw_ila 列表 |
| 导出 XSA 报 only synthesized/implemented | 实现状态 | 工程未完成实现或当前设计不是 implemented | 完成 impl 后再 `write_hw_platform` |
| 注释变乱码 | 文件编码 | GBK/UTF-8 混用、编辑器错误转码 | 只做 ASCII 替换并核对原编码 |
| 文件名跨平台失败 | 大小写和空格 | Windows 大小写不敏感隐藏问题 | 在 Linux 解压并检查 include 路径 |

## 证据优先级

1. 工具实际输出；
2. ILA/串口原始数据；
3. 上板画面；
4. 源码结构；
5. 旧报告或历史经验。

遇到互相矛盾的信息时，以新生成产物和当前实测数据为准。
